## 2024-08-01 - [UI/UX Improvement] Markdown support in AnimatedTypewriterText
**Инсайт:** Обычная анимация побуквенного вывода не работает хорошо с `AnnotatedString` без пересчета стилей для каждого состояния.
**Действие:** Вычисляем `AnnotatedString` один раз, а затем используем `.subSequence(0, length)` для анимированного вывода текста с поддержкой форматирования (жирный/курсив). Это улучшает производительность, так как парсинг markdown выполняется только один раз.

## 2024-08-01 - [Bug Fix] AnimatedTypewriterText regenerating old messages
**Инсайт:** `AnimatedTypewriterText` всегда анимировал текст с нуля при рекомпозиции или прокрутке, что создавало эффект "повторной генерации" старых сообщений.
**Действие:** Добавлен флаг `isAnimated` в `AnimatedTypewriterText`. Теперь анимация проигрывается только для последнего сообщения (`isLastMessage = true`), а старые сообщения сразу рендерятся полностью. Это решает проблему и улучшает производительность при скролле.

## 2024-08-01 - [Feature] Mature Content 18+ Toggle
**Инсайт:** Пользователям нужен явный контроль над цензурой генерируемого контента.
**Действие:** Добавлен тоггл "Взрослый Контент (18+)" в настройки. Теперь профиль хранит этот флаг, который можно будет передавать в системный промпт LLM для управления степенью откровенности/насилия в генерациях.
