## 2024-08-01 - [UI/UX Improvement] Markdown support in AnimatedTypewriterText
**Инсайт:** Обычная анимация побуквенного вывода не работает хорошо с `AnnotatedString` без пересчета стилей для каждого состояния.
**Действие:** Вычисляем `AnnotatedString` один раз, а затем используем `.subSequence(0, length)` для анимированного вывода текста с поддержкой форматирования (жирный/курсив). Это улучшает производительность, так как парсинг markdown выполняется только один раз.
